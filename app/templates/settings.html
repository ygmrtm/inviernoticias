🔑 Lista de Claves de API de Gemini (Rotación Automática por Cuota)

Configura tu lista de claves de API de Google Gemini. El sistema utiliza la clave activa para el análisis y, si se agota su cuota (Error 429 / RESOURCE_EXHAUSTED), conmutará automáticamente a la siguiente clave de la lista, luego a la siguiente y así sucesivamente. Si todas las claves agotan su cuota, la tarea se enviará a la cola DLX de RabbitMQ para reintentar más tarde.
